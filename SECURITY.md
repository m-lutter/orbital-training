# Security policy

## Supported version

Orbital Training is currently in beta. Security fixes are applied to the latest
code on the default branch and the current production deployment only.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use
[GitHub private vulnerability reporting](https://github.com/m-lutter/orbital-training/security/advisories/new)
when it is available for this repository.

Include the affected route or component, the impact, and the minimum steps needed
to reproduce the issue. Do not include real account credentials, access tokens,
health records, workout data, or other personal information. Use synthetic data
and redact request or response captures before attaching them.

Issues about training-methodology preferences without a security or privacy impact
can use the normal issue tracker after public issue tracking is enabled.
